# Секундомер для жонглирования (HTML + JS)

Однофайловое веб‑приложение: **Пробел** запускает попытку, а следующее нажатие завершает её, записывает результат и автоматически запускает отсчёт до следующей попытки. Поддерживает настраиваемый *предстартовый отсчёт* для подготовки к запуску.

> Файл из репозитория: `index.html`. Работает офлайн в любом современном браузере.

---

## Возможности

* ✅ **Один пробел после падения**: результат записывается, таймер обнуляется и сразу начинается отсчёт до следующей попытки.
* ✅ **Удаление строк** по клику на значок `×` у строки; нумерация пересчитывается автоматически.
* ✅ **Предстартовый отсчёт** (3–5 сек) — включается при первом нажатии *Space*, когда таймер на `00:00:00.000`.

  * Во время отсчёта **Space** — моментальный запуск без ожидания.
* ✅ **Горячие клавиши игнорируются**, если фокус в интерактивных элементах (ползунок, кнопки и т. п.).
* ✅ Формат времени: `чч:мм:сс.мс` (миллисекунды, три знака).
* ✅ Точная отрисовка на базе `requestAnimationFrame` (без дрейфа `setInterval`).

---

## Быстрый старт

1. Сохраните код из файла `index.html` (лежит в этом репозитории).
2. Откройте его двойным кликом — запустится в браузере локально, без сервера.
3. Нажмите **Пробел** — после предстартового отсчёта запустится таймер.
4. Когда мячи упали, нажмите **Пробел** один раз: результат сохранится, а отсчёт до следующей попытки начнётся автоматически.

---

## Горячие клавиши

| Состояние таймера | Действие по пробелу |
| --- | --- |
| `00:00` | Запустить предстартовый отсчёт. |
| Идёт отсчёт | Пропустить оставшееся время и стартовать сразу. |
| Таймер работает | Записать результат, обнулить таймер и автоматически запустить отсчёт следующей попытки. |

> Примечание: если фокус в элементах формы (ползунок, кнопки и т. д.), клавиши не перехватываются, чтобы не мешать управлению элементами.

---

## Элементы интерфейса

* **Табло времени** — большое число с миллисекундами.
* **Три ряда кнопок режима**: количество мячей, режим рук и тип жонглирования. Активный вариант выделен цветом.
* **Основная кнопка** дублирует пробел: `▶️ Старт` / `⏹ Завершить и повторить` / `⏭ Начать сейчас`.
* **Кнопка `🧹 Очистить таблицу`** удаляет результаты текущего режима.
* **Ползунок «Отсчёт перед стартом»** — 3–5 сек, по умолчанию 3 сек. Число справа показывает выбранное значение.
* **Таблица результатов** — колонки: №, результат, метка времени, `×` (удаление строки).

## Пользовательские настройки

### Время отсчёта

На панели управления — ползунок **«Отсчёт перед стартом»** (min: 3, max: 5, шаг 1 сек).

> Нужно больше диапазон (например, 0–10 сек)? Измените атрибуты `min/max/value` у `<input type="range" id="prestart">`.

### Внешний вид

* Цвета задаются CSS‑переменными в `:root` (`--bg`, `--card`, `--text`, `--accent` и др.).
* Размер цифр отсчёта — класс `.countdown-digit` (используется `clamp(...)`).

---

## Как это устроено

* **Таймер**: `requestAnimationFrame` + `performance.now()`; завершение попытки фиксирует `elapsedMs`, сохраняет результат и запускает следующий предстартовый отсчёт.
* **Отсчёт**: отдельный цикл rAF; при завершении — мгновенно запускает таймер; отмена/пропуск убирает оверлей и чистит текст.
* **Список результатов**: DOM‑строительство строки + авто‑переиндексация при удалении.
* **Доступность (a11y)**: табло времени помечено `aria-live="polite"`.

Структура файла (всё в одном `index.html`):

```
<style>  /* тема, таблица, кнопки, отсчёт */ </style>
<body>
  <div class="card">
    <!-- Строка отсчёта -->
    <!-- Блок с табло и бейджами -->
    <!-- Панель управления + ползунок отсчёта -->
  </div>
  <div class="card"> <!-- Таблица результатов --> </div>
<script> /* логика секундомера, отсчёта и таблицы */ </script>
```

## Экспорт и сохранение

Сейчас данные **не сохраняются** между перезагрузками и **не экспортируются**. Возможные улучшения:

* сохранение результатов в `localStorage`;
* экспорт в CSV/TSV и копирование в буфер обмена;
* расчёт сумм/средних/медианы по сериям;
* звуковой сигнал `3‑2‑1‑старт`.

Если нужна любая из функций — опишите желаемый формат, добавим.

## Известные ограничения

* Точность ограничена кадровой частотой и таймингами браузера, но достаточна для пользовательского учёта времени с миллисекундами.
* На iOS/Android жесты/клавиатура могут отличаться; рекомендуется использовать кнопки‑дубликаты.
