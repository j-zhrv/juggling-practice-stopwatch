# Секундомер для жонглирования (HTML + JS)

Однофайловое веб‑приложение для серийной практики жонглирования. **Пробел** запускает попытку, а следующее нажатие завершает её, сохраняет результат и автоматически запускает отсчёт до следующей попытки.

> Основной файл — `index.html`. Таймер и журнал результатов работают локально в современном браузере.

---

## Возможности

* ✅ **Один пробел после падения** — сохранить результат и сразу перейти к следующему циклу.
* ✅ **Кнопка «Остановить цикл»** — прекратить отсчёт или текущую попытку без записи незавершённого результата.
* ✅ **Предстартовый отсчёт** — 3, 5, 7, 10 или 15 секунд; по умолчанию **7 секунд**.
* ✅ **Быстрый выбор режима** — отдельные кнопки для количества мячей, рук и типа жонглирования.
* ✅ **Общая таблица результатов** — в каждой строке видны мячи, руки и тип жонглирования.
* ✅ **Отдельный рекорд для каждого режима** — результаты разных комбинаций не конкурируют между собой.
* ✅ **Пауза на празднование рекорда** — попытки и время сессии останавливаются до выбора пользователя.
* ✅ **Разнообразное позитивное подкрепление** — шесть вариантов иллюстраций, цветов, бейджей, заголовков и сообщений.
* ✅ **Конфетти и аплодисменты** — для каждого строгого улучшения рекорда режима.
* ✅ **Сохранение в `localStorage`** — результаты и основные настройки остаются после перезагрузки.
* ✅ Удаление отдельных строк, очистка всей таблицы и скачивание скриншота результатов.

## Основной цикл

1. Выберите количество мячей, режим рук и тип жонглирования.
2. Нажмите **Пробел** — начнётся предстартовый отсчёт.
3. Во время отсчёта можно нажать **Пробел** ещё раз, чтобы начать немедленно.
4. Когда мячи упали, нажмите **Пробел** один раз.
5. Обычный результат сохраняется, после чего автоматически начинается следующий 7‑секундный отсчёт.
6. Если результат побил рекорд текущего режима, весь процесс ставится на паузу и открывается экран победы.
7. После празднования выберите:
   * **▶ Продолжить тренировку** — возобновить время сессии и запустить следующий отсчёт;
   * **⏹ Закончить на рекорде** — закрыть тренировочную сессию, сохранив результат.
8. Вне экрана рекорда цикл можно остановить кнопкой **⏹ Остановить цикл** без записи текущей незавершённой попытки.

## Экран рекорда

Экран не закрывается автоматически. Он остаётся открытым, пока пользователь сам не выберет дальнейшее действие. На это время:

* новая попытка не запускается;
* предстартовый отсчёт не идёт;
* время тренировочной сессии не расходуется;
* глобальная горячая клавиша пробела не запускает скрытый цикл;
* фокус переводится на кнопку продолжения.

Чтобы визуальное подкрепление не превращалось в один и тот же незаметный баннер, шесть вариантов чередуются без немедленного повтора:

| Вариант | Бейдж | Иллюстрация |
| --- | --- | --- |
| Новая вершина | «Пробит новый потолок» | гора и флаг |
| Уровень повышен | «Level up» | растущие стрелки |
| Ты в огне | «Режим разогрет» | пламя |
| Новая орбита | «Траектория роста» | ракета |
| Рекорд принадлежит тебе | «Корона режима» | корона |
| Граница сдвинута | «Прорыв» | молния |

Каждый вариант также использует собственную цветовую пару и текст. Конфетти генерируется заново, а аплодисменты синтезируются через Web Audio API.

## Режимы и рекорды

Режим определяется комбинацией трёх параметров:

* количество мячей: 2, 3 или 4;
* руки: только левая, только правая или двумя руками;
* тип: по часовой стрелке, против часовой стрелки, Mixed или синхронно.

Таблица общая для всех комбинаций, но лучший результат вычисляется **внутри конкретного режима**. Например, рекорд для «3 мяча · двумя руками · Mixed» не сравнивается с рекордом для четырёх мячей.

Первый результат режима создаёт исходную планку. Экран победы запускается, только когда следующий результат строго превышает эту планку.

## Управление

| Состояние | Пробел | Дополнительное действие |
| --- | --- | --- |
| Таймер остановлен | Запустить отсчёт | — |
| Идёт отсчёт | Начать немедленно | «Остановить цикл» отменяет отсчёт |
| Идёт попытка | Записать результат и запустить следующий отсчёт | «Остановить цикл» завершает без записи |
| Открыт рекорд | Активирует сфокусированную кнопку продолжения | `Esc` заканчивает тренировку на рекорде |

Горячая клавиша не перехватывается, когда фокус находится в поле ввода, ползунке, select или кнопке.

## Таблица результатов

Колонки слева направо:

1. мячи;
2. руки;
3. тип жонглирования;
4. номер;
5. результат;
6. метка времени;
7. удаление строки.

Текущий лучший результат каждого режима отмечается кубком 🏆. Кнопка **«Очистить таблицу»** удаляет результаты всех режимов.

## Реализация

* Таймер попытки: `requestAnimationFrame` + `performance.now()`.
* Пауза сессии на рекорде: останавливает rAF и сдвигает `sessionStartTimestamp` на длительность празднования.
* Результаты: объект `allResultsByMode` в `localStorage`; таблица строится как единая хронологическая проекция.
* Рекорд: максимум `elapsedMs` отдельно для каждого ключа режима.
* Иллюстрации: шесть встроенных SVG без дополнительных файлов и сетевых запросов.
* Аплодисменты: короткие шумовые импульсы через Web Audio API.
* Анимация: CSS‑появление, плавающая SVG‑иллюстрация и динамические частицы конфетти.

---

## Известные ограничения

* Браузер может заблокировать или не поддерживать Web Audio; в этом случае экран и конфетти всё равно появятся, но звук может не воспроизвестись.
* Формат отображения времени — `мм:сс`.
* Скриншот таблицы зависит от загрузки `html2canvas` с CDN.
* На мобильных устройствах управление клавиатурой может отличаться.
